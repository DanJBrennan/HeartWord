# Chapter Title Card

## Scope

Every chapter video opens with a short title card identifying the book +
chapter (in the target/heart language) and the language name, so a viewer
can immediately see what the video covers and what language it's in.
Decided with Dan 2026-09-10 (Mark 2 healing-sequence pass): **opening card
only** — no persistent on-screen mark for the rest of the runtime. Two
options were mocked up (card-only vs. card + a persistent bottom-left
corner mark surviving the whole video); Dan chose card-only to keep the
rest of the runtime clean.

## Spec

- **Duration**: 2-3 seconds, at the very start of the chapter, before the
  first story shot.
- **Background**: the chapter's own opening establishing shot (e.g. Mark
  2's bird's-eye Capernaum shot), darkened ~50% with a flat black overlay
  for text legibility — not a separate/blank card. This keeps the card
  visually tied to the chapter rather than feeling like a generic slate.
- **Title text**: book + chapter number, in the heart language's own
  script/spelling (e.g. "MARKUS 2" for Hatam Mark 2) — not the English
  book name. Centered, Georgia Bold, large (scaled ~7% of frame height at
  1280x720 => ~92-96px), white with a soft drop shadow (offset ~3px,
  ~60% black).
- **Language label**: the language's own name (e.g. "HATAM"), letter-spaced
  ("H A T A M"), centered directly beneath the title with a thin horizontal
  rule between them, Trebuchet MS regular, ~32px, white at ~85% opacity.
- **No AI-rendered text**: this card is a real composited graphics overlay
  built with a font-rendering tool (e.g. Pillow), never generated by the
  image/video providers — every provider prompt in this pipeline already
  forbids in-scene text/labels (see `CASTING_ANCHOR` in the keyframe
  generation scripts), so the title card is assembled after the fact, not
  requested from a shot's own generation.
- **Per-chapter parameters**: only the title text and language label change
  per (language, book, chapter) project (see `docs/design/timeline.md`'s
  "Project Identity" section) — background frame, fonts, sizes, and layout
  stay fixed across every chapter for a consistent series identity.

## Reference implementation

`scripts/build-chapter-title-card.ts` — generates the card PNG from a
background frame + title/label text, matching this spec. Used for both the
Blender editor timeline and the ffmpeg chapter-assembly pipeline; see each
project's own build script for how the card clip is spliced in as the
first segment (2-3s, silent/ambient under it, no narration — narration
starts with the first real story shot, per the existing "narrator must
never go silent" rule, which only applies once the story itself begins).
