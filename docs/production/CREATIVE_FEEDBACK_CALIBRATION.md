## Small proposed rubric

`heartword-craft-v1` uses clarity, emotional development, pacing, continuity of
presentation and feasibility, each weighted 20%. Equal weights are a transparent
starting convention; there is no evidence for optimized weights. Source/canon
continuity, actual source performance and feasibility prerequisites remain
independent non-negotiable checks.

Ordinal anchors: 0 seriously ineffective, 1 weak, 2 mixed, 3 adequate for the
stated intent, 4 strong. Every rating needs an observable or explicitly
prospective basis, shot/beat locators, confidence and limitations. Unobservable
dimensions are null and make a full comparable total unavailable. Confidence
never multiplies a quality score. Compare only the same milestone, rubric and
source/media scope; a treatment judgment is not a watched-film judgment.

An illustrative target is at least 3/4 in every dimension (75/100). **It is
uncalibrated, inactive and not used by runtime acceptance.** An average of 75
would also hide weak dimensions; neither form estimates audience approval.
The implemented loop instead uses an evidence-backed reviewer recommendation,
hard-check separation, dimensional improvement and explicit finite limits.

A future numeric cutoff decision needs Dan-adjudicated retained artifact pairs
using this rubric and intent, including both accepted and rejected cases,
and an unseen chapter comparison through the existing evaluation workflow.
Until that evidence exists, leave the numeric threshold inactive. No separate
chapter-plan approval is requested. Labels for calibration are a remaining
evaluation need, not a blocker to this bounded evidence-based loop.
