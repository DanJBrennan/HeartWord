# Scene 1, Shot 2: production rationale

Mark 2:2 moves inside the same Capernaum house. The requirement is literal:
there is no room even at the door while Jesus teaches. The roof is still
intact, so the later roof-opening lighting language is excluded. This image
must follow Shot 1’s exterior establishing image with the same dark-basalt,
low flat-roof house and dense, irregular crowd.

The cast requires Jesus, four distinct scribes, and two continuing crowd
witnesses from their approved Papuan canon. The scribes sit as the shot asks;
there is no dispute or accusation yet. This remains a non-lip-sync medium
frame, so Jesus is readable but not framed as a dialogue close-up.

Acceptance: packed interior and blocked doorway are legible; intact timber,
reed/branch and earth roof; Jesus and named cast each once; clear, historically
coherent first-century setting; no roof-opening action, paralytic or carriers.
