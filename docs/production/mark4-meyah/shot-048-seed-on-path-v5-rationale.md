# Mark 4:14 sowing backswing

The fourth candidate removed the blue cuff and kept the source-grounded path,
but its fully extended palm was judged unworkable for a broadcast throw. This
revision places only an anonymous cropped hip-level pouch, bent forearm and
seed-holding hand at the far edge, before the outward sweep. It preserves the
empty named cast, exposed earlier seed, field and lake. The rejected poses and
their QC remain in history.
